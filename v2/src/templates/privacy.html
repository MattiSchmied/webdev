Hosting mit GitHub Pages

Diese Website wird über GitHub Pages bereitgestellt. Beim Aufruf werden technisch notwendige Verbindungsdaten, insbesondere Ihre IP-Adresse, die angeforderte Datei und Angaben des Browsers, an GitHub übermittelt. Rechtsgrundlage ist Art. 6 Abs. 1 lit. f DSGVO.

GitHub verarbeitet Daten auch außerhalb der Europäischen Union, insbesondere in den USA. Informationen zur Verarbeitung, internationalen Übermittlung und Speicherung finden Sie in der Datenschutzerklärung von GitHub (öffnet in einem neuen Tab).
