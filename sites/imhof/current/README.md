# Friseur Imhof · aktuelle Fassung

Der Build im Repository-Hauptordner veröffentlicht diese Fassung unter `/reta/imhof/akt/`. Für eine eigenständige Ausgabe kann `node src/build.ts` in diesem Ordner ausgeführt werden; `node src/check.ts` prüft diese Ausgabe unter `dist/`. Beide Befehle benötigen Node.js 24.

HTML-Vorlagen stehen in `src/templates/`, Gestaltung und Browsercode in `src/styles.css` und `src/client.ts`. Die Original-Preislisten liegen in `assets/documents/`; Recherche, Prüfsummen und Bildnachweise stehen in `research/`. Die 51 Positionen der Original-PDFs ergeben 50 Website-Positionen, weil die Anfahrt in beiden PDFs enthalten ist.

Die Haarillustration ist KI-generiert und auf der Website entsprechend beschriftet. Das Porträt und Logo stammen von der Originalseite. Die eingebettete Karte wird erst nach Zustimmung geladen.
